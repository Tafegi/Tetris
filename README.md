# Tetris

## Огляд

Tetris — це десктопна реалізація класичної гри-головоломки, розроблена мовою C++ з використанням архітектурного патерну MVC (Model–View–Controller).

Проєкт створено як навчальний з програмної інженерії з акцентом на:

* **Об'єктно-орієнтоване програмування (ООП):** інкапсуляція логіки, правильне використання **конструкторів та деструкторів** для безпечного управління життєвим циклом об'єктів.
* Архітектуру MVC, що чітко розділяє чисту логіку та графічний рендеринг.
* Сучасні можливості C++ (стандарт C++20), включаючи розумні вказівники (ідіома RAII) та `std::optional`.
* Подійно-орієнтоване управління вікнами та вводом.
* Реалізацію ігрового циклу з обробкою незалежного від кадрів часу (delta time).

## Можливості

### Геймплей

* Класична механіка Тетрісу за офіційними стандартами Guideline.
* Система супер-обертання (SRS) з просунутими відштовхуваннями від стін (wall kicks).
* Підтримка миттєвого падіння (Hard drop) з відображенням фігури-привида (Ghost piece) та прискореного падіння (Soft drop).
* Система утримання фігури (Hold) з блокуванням на один хід.
* Система рандомізації "7-bag" для рівномірного та передбачуваного розподілу фігур.
* Панель попереднього перегляду (NEXT) на 5 наступних фігур.
* Очищення ліній з системою нарахування очок за стандартом (Single, Double, Triple, Tetris).
* Прогресія рівнів з динамічною гравітацією, що розраховується за формулами.
* Затримка автозсуву (DAS) та частота автоповтору (ARR) для плавного безперервного руху фігури при затисканні клавіш.
* Збір статистики щодо випадіння фігур та типів очищених ліній.

### Технічні особливості

* Інтеграція графічної бібліотеки **SFML 3** для графіки, тексту та управління вікном.
* Попередньо обчислені матриці обертання та таблиці wall-kick (оптимізація продуктивності).
* Надійна машина станів (State Machine) для управління потоком додатку: *Меню, Гра, Пауза, Кінець гри, Статистика*.
* Комплексна обробка подій миші та клавіатури.
* Резервні шрифти (Fallbacks) для кросплатформної сумісності.

## Архітектура

Додаток суворо дотримується патерну **MVC**.

### Модель (Model)

Відповідає за:
* Чисту ігрову логіку та стан без жодних залежностей від графічного рендерингу.
* Матрицю ігрового поля (Board) та виявлення зіткнень (Колізій).
* Нарахування очок, підвищення рівнів та таймінги гравітації.
* Математику обертання фігур (SRS) та зміщення при зіткненнях (wall-kick).

### Вигляд (View)

Відповідає за:
* Рендеринг ігрового поля, падаючої фігури, фігури-привида та інтерфейсу (HUD).
* Відмальовування меню, екранів статистики та напівпрозорих оверлеїв (напр., Пауза).
* Управління фігурами, кольорами та шрифтами за допомогою модулів SFML.

### Контролер (Controller)

Відповідає за:
* Обробку вводу користувача через події SFML (клавіатура та миша).
* Передачу дій гравця до Моделі (керування грою).
* Управління переходами між екранами та станами додатку.
* Обробку логіки автоповторення введення (DAS/ARR).

## Принципи проєктування

Проєкт дотримується найкращих практик розробки:

* **Принципи SOLID**.
* **Принцип єдиної відповідальності (SRP):** наприклад, створено окремі спеціалізовані менеджери для Score, Level, Hold, Queue.
* **Безпечне управління ресурсами (RAII):** автоматичне вивільнення пам'яті гарантується продуманими деструкторами та використанням сучасних розумних вказівників (`std::unique_ptr`). Конструктори налаштовують об'єкти у повністю валідному стані одразу при їх створенні.
* **Суворе розділення обов'язків:** класи View *лише читають* дані з Моделі, класи Controller *лише викликають зміни* у Моделі.
* **Інкапсуляція логіки** за чистими та зрозумілими публічними інтерфейсами.
